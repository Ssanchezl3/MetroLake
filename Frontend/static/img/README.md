# Imágenes del frontend

## `tren.jpg` (hero del Panel general)

El Panel general muestra un **hero** con la foto del tren del Metro de Medellín
partida en dos mitades (una artística a color y otra técnica con datos).

Para usar la foto real, coloca aquí el archivo con este nombre exacto:

```
Frontend/static/img/tren.jpg
```

Recomendado: una foto horizontal del tren (por ejemplo 900×600 px o similar).

Si el archivo **no existe**, el hero muestra automáticamente un tren
vectorial (SVG) de respaldo, por lo que la página nunca se ve rota.
